<objective>
Let a developer wipe and recreate the fashion flash-sale data in one command, and reset one or every sale between measurement runs through a single shared reset service.

Purpose: Seed is the handoff to the demo and to the Phase 3 load scripts (credentials, saleId, stock size). The reset service is the one implementation that the Phase 2 admin route will call, so the CLI and the API can never drift apart.
Output: `scripts/cli-args.ts`, `services/seed.service.ts` + `scripts/seed.ts`, `services/sale-admin.service.ts` + `scripts/reset.ts`, unit tests for argument parsing and integration tests for seed and reset.

Decisions implemented: D-01, D-02, D-03, D-04, D-05, D-06, D-08, D-21 (seed), D-07, D-09 (reset). Claude's-discretion choice: the reset `stock_movements` row records `delta = totalQty` (the full stock that reset restores after deleting every order), documented in a Vietnamese code comment.
</objective>

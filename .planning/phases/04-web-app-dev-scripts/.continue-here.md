# 04-04 Task 1 — Chờ duyệt luồng mua

Task 1 đã nối auth, điều hướng và trang sale qua API thật. Khách bấm mua đi qua đăng nhập hoặc đăng ký rồi quay lại cùng sale. Phiên giữ qua reload. Nút mua kiểm tra mốc kết thúc theo giờ server và khóa trước khi gửi.

- Frontend: 30/30 test, typecheck và build đạt. Backend: typecheck và build đạt. Fixture: `node --check` đạt.
- Edge: mật khẩu sai giữ nguyên form, tài khoản mẫu đăng nhập đúng, hai lần nhấp chỉ gửi một POST Bearer với `mode=v2` và `qty: 1`. API trả 201, tồn kho từ 100 xuống 99 và trang giữ xác nhận mua.
- Đăng ký ở 320px tự lưu phiên và về cùng sale. Phiên giữ qua reload rồi được xóa khi đăng xuất. Kiểm tra bố cục ở 320, 390 và 1440px theo bằng chứng trong `frontend/DESIGN.md`.
- Fixture ban đầu trả 500 do thiếu đăng ký Lua V2. Đã gọi `registerBuyScript` giống server chính rồi kiểm thử thành công trên một fixture mới.
